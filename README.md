# BluePeak Development documentation

Upload this project to a GitHub repository. Open Settings > Pages and select GitHub Actions. Push to main/master or run the Documentation workflow.

See [PUBLISHING.md](PUBLISHING.md) for preview, deployment, and instructions for adding resources. This archive contains documentation and setup downloads, not the game resource source.

The public site is a resource documentation hub. Each script has its own folder under `docs/` and an expandable sidebar entry. Inventory is the first resource, under `docs/inventory/`.
